# Contribuire a Verbalia Open

Grazie per il contributo. Issue e pull request sono benvenute, preferibilmente con un caso fittizio riproducibile.

1. Apri issue senza dati personali reali.
2. Scrivi test per ogni modifica a quorum o validazioni; cita norma, testo vigente, data e casi limite.
3. Esegui `python -m unittest discover -s tests -v` e controlla eventuali documenti esportati.
4. Descrivi cambiamenti di comportamento e aggiornali in `CHANGELOG.md`.
5. Una regola giuridica non si modifica con sola intuizione o un post social: servono fonti attendibili e validazione professionale.
6. Nessuna credenziale, trascrizione reale, documento cliente o dato sensibile nei commit.

I contributi vengono pubblicati con licenza MIT.
